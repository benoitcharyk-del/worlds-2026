# Worlds 2026 Live

Calendrier, scores en direct, classement de la phase suisse et playoffs des Worlds 2026 de League of Legends, en heure de Paris.

Site de fan non officiel, sans but commercial. Worlds 2026, le logo, les visuels et les logos d'equipes appartiennent a Riot Games et aux equipes concernees.

## Fonctionnement

- Page statique (`index.html`), hebergee par GitHub Pages.
- Le navigateur lit directement l'API publique de lolesports.com toutes les 45 secondes : scores, horaires, affiches.
- Aucune installation ni tache planifiee : tant que lolesports.com publie les donnees, la page est a jour.
- Favoris et corrections de score sont gardes dans le navigateur de chaque visiteur.
